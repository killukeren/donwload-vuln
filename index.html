    Why it works: Firefox sanitizes ASCII : and / in download
    filenames, but not the Unicode lookalikes ∶ (U+2236) and ∕
    (U+2215). Zen renders the filename in an HTML span with
    text-overflow: ellipsis, which hides the tail — where the real extension
    lives. U+2800 padding pushes the extension past the ellipsis without
    showing visible filler.
  

  

    Firefox 160 is not affected by this variant: its download item uses
    crop="center", so the extension stays visible.
